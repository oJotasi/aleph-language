# Aleph

Aleph es un lenguaje interpretado orientado a listas y conjuntos,
implementado en C utilizando Flex y Bison.

## Características

- Operaciones de conjuntos:
  - unión
  - intersección
  - diferencia

- Operaciones sobre listas:
  - push
  - pop
  - concatenación

- Estructuras de control:
  - if
  - while
  - for each

- Funciones definidas por el usuario

## Estructura
  - Lexer → Flex
  - Parser → Bison
  - AST → C
  - Evaluador semántico


## Requisitos

- GCC
- Flex
- Bison

## Compilación

```bash
.\aleph.exe
```
```bash
.\build.bat
```
